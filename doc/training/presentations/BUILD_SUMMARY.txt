🔧 BUILD SYSTEM COMMANDS
─────────────────────────────────────────────────────────────

make labs               Build all 23 lab documents
make diagrams           Generate all TikZ diagrams

make clean              Remove auxiliary files
make cleanall           Remove ALL generated files
make rebuild            Clean and rebuild from scratch
make help               Show detailed help

🔄 REGENERATING DIAGRAMS
─────────────────────────────────────────────────────────────
To customize and regenerate diagrams:

1. Edit TikZ source:
   vi images/diagrams/class_a_diagram.tex

2. Regenerate diagrams:
   make diagrams

3. Rebuild presentations:
   make courses

All diagrams will be automatically updated in the PDFs!
